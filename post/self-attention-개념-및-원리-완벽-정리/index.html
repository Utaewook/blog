Self Attention 개념 및 원리 완벽 정리

Transformer의 핵심인 Self Attention의 개념과 Query, Key, Value 연산 원리를 알아봅니다.

01, 2026
2 minute read

Self Attention (셀프 어텐션)

Self Attention은 입력 시퀀스 내의 각 단어(또는 토큰)가 서로 어떤 연관성이 있는지를 계산하여, 문맥(Context)을 더욱 정확하게 파악할 수 있도록 돕는 메커니즘이다. 구글의 “Attention Is All You Need” 논문에서 소개된 Transformer 아키텍처의 핵심 원리.

1. 등장 배경 및 필요성

기존의 RNN이나 LSTM은 문장을 순차적으로(Sequential) 처리하기 때문에 다음과 같은 문제가 존재.

  • 거리에 따른 정보 손실 (Long-Term Dependency): 문장이 길어질수록 앞부분의 정보가 뒤쪽까지 잘 전달되지 않음.
  • 병렬 처리 불가: 단어를 순서대로 처리해야 하므로 학습 속도가 느림.

Self Attention은 “입력된 모든 단어를 동시에 한 번에 보면서 각 단어들 사이의 연관성을 계산” 하기 때문에 위 문제들을 효과적으로 해결

2. 핵심 원리: Q, K, V (Query, Key, Value)

Self Attention은 데이터베이스 검색 시스템과 유사한 Query, Key, Value 개념을 사용한다. 해당 내용이 가장 핵심이지만, 처음 볼 때 이해하기가 어려운 부분이라. 각 입력 단어는 학습 가능한 가중치 행렬과 곱해져 세 가지 벡터를 생성한다.

  • Query (Q - 질문): 현재 처리 중인 단어가 “나는 지금 어떤 정보가 필요해?“라고 묻는 주체.
  • Key (K - 색인/태그): 다른 모든 단어들이 “나는 이런 정보를 가지고 있어"라고 알려주는 기준값.
  • Value (V - 실제 값): 다른 단어들이 실제로 가지고 있는 고유의 정보(의미).

💡 비유하자면: 유튜브 검색창에 ‘딥러닝 기초’(Query)를 치면, 유튜브는 각 영상의 제목과 태그(Key)를 비교해서 연관성이 높은 영상들의 실제 비디오(Value)를 보여줍니다.

3. Self Attention 연산 과정

Self Attention은 Scaled Dot-Product Attention 방식을 주로 사용하며, 아래와 같은 순서로 진행된다.

  1. 내적 연산 (Dot Product): 각 단어의 Query를 모든 단어의 Key와 내적(Dot Product)합니다. 두 벡터가 유사할수록 내적 값(어텐션 스코어)이 커짐
  2. 스케일링 (Scaling): 내적 값이 너무 커지는 것을 방지하기 위해 $d_k$ (Key 벡터의 차원 수)의 제곱근인 $\sqrt{d_k}$ 로 나누어줌.
  3. 소프트맥스 (Softmax): 스케일링된 값에 Softmax 함수를 취해 0~1 사이의 확률값(비율)으로 만듭니다. (이 합은 1) 이것이 바로 Attention Weights!
  4. 가중합 (Weighted Sum): 구형된 Attention Weights와 각 단어의 Value 벡터를 곱하여 더한다.

수식

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

4. Multi-Head Attention (멀티 헤드 어텐션)

단일 Self Attention만 사용하면 한 가지 관점에서의 문맥만 파악할 수 있다. 이를 보완하기 위해 Q, K, V 벡터를 여러 개(Head)로 나누어 동시에 여러 관점에서 어텐션을 수행하는 것이 Multi-Head Attention입니다.

  • 예: 한 Head는 ‘문법적 관계’에 집중하고, 다른 Head는 ‘의미적 연관성’에 집중할 수 있다.

5. 장단점 요약

👍 장점

  • 장기 의존성 문제 해결: 거리에 상관없이 문장 내 모든 단어 간의 관계를 직접 계산.
  • 병렬 처리 (Parallelization): 행렬 곱셈 연산으로 한 번에 처리 가능하므로 RNN 대비 학습 속도가 빠름

👎 단점

  • 메모리 및 계산 비용: 문장 길이가 $N$일 때 연산량이 $O(N^2)$로 증가하므로, 매우 긴 문장 처리에는 부하가 크다.
  • 위치 정보 부재: 단어의 순서(위치) 정보를 본질적으로 포함하지 않아, 추가적인 위치 인코딩(Positional Encoding)이 필요.
