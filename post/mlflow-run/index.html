Run

2026년 11월 4일
1 minute read

Run은 학습 한 번의 기록이다. 그 학습에 넣은 설정과 나온 결과가 run 하나에 묶인다.

1. 구성

항목내용
run id32자리 16진수. 자동으로 생성됨
run 이름직접 정하거나, 안 정하면 popular-yak-652 같은 이름이 붙는다
기록Parameter, Metric, Tag, Artifact, Dataset
상태, 시작·종료 시각자동

2. 만들기

with mlflow.start_run(run_name="lr0.05"):
    mlflow.log_params(params)
    model = train(params)
    mlflow.log_metric("mae", evaluate(model))

with 블록 하나가 run 하나. 블록 안의 mlflow.log_*는 지금 열린 run(active run)에 기록된다.

3. 상태

상태언제
RUNNING블록에 들어갈 때
FINISHED블록을 정상으로 빠져나올 때
FAILED블록 안에서 예외가 났을 때

파라미터를 학습 전에 남겨 두면, 학습이 죽어 FAILED가 돼도 무엇을 시도했는지는 남는다.

4. 부모와 자식 run

start_run(nested=True)로 run 안에 run을 만든다. 자식 run에는 mlflow.parentRunId 태그가 붙는다. 하이퍼파라미터 탐색에서 탐색 전체를 부모, 시도 하나를 자식으로 둘 때 쓴다. 추후에 Optuna와 함께 사용할 때 유용할 듯?
