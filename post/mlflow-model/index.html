Model

2026년 11월 24일
1 minute read

MLflow Model은 모델을 저장하는 형식이다. 모델 파일과 그 모델을 불러오는 데 필요한 정보를 폴더 하나에 같이 둔다.

1. 모델 폴더

model/
├── MLmodel                      불러오는 방법 (flavor, 입력·출력 형식)
├── model.skops                  학습된 모델 (프레임워크마다 다름)
├── requirements.txt             필요한 패키지 (conda.yaml, python_env.yaml도 같이)
├── input_example.json           입력 예시
└── serving_input_example.json   REST로 서빙할 때 보낼 요청 본문

핵심은 MLmodel 파일이다. 이 파일만 읽으면 어떤 라이브러리로 어떻게 불러올지 알 수 있다.

2. 저장 방법

함수저장 위치기록
mlflow.<flavor>.save_model(model, path)지정한 로컬 폴더안 남음
mlflow.<flavor>.log_model(model, name="model")Artifact StoreLoggedModel로 남음

보통 log_model을 씀. 인터페이스에 대한 자세한 사항은 공식 문서 참조해야함

3. 저장 포맷

  • scikit-learn, LightGBM 모델은 pickle이 아니라 skops 형식으로 저장된다. pickle은 불러오는 순간 임의 코드가 실행될 수 있는데, skops는 허용된 타입만 되살린다.
  • requirements.txt는 모델을 한 번 불러 보면서 import되는 패키지를 추론한 결과다. 필요 없는 패키지가 섞일 수 있다.

4. 불러오기

model = mlflow.sklearn.load_model(uri)  # 원래 프레임워크 객체로
model = mlflow.pyfunc.load_model(uri)   # 공통 인터페이스로

관련: Flavor, LoggedModel, Model URI
