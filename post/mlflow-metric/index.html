Metric

2026년 11월 4일
1 minute read

Metric은 학습 결과로 나온 숫자다. 손실, 정확도, MAE 같은 것. 대부분 지표를 저장하고 비교하는걸로 사용될테지만, 사실 숫자면 뭐든 들어갈 수 있다.

1. 특징

  • 같은 이름으로 여러 번 남길 수 있다. step(몇 번째인지)을 붙이면 곡선이 된다. step을 안 주면 0이다.
  • 이력이 전부 남고, run 목록에는 마지막 값이 보인다.

2. 사용법

for epoch, loss in enumerate(losses):
    mlflow.log_metric("loss", loss, step=epoch)
mlflow.log_metrics({"mae": 1.79, "rmse": 2.41})

3. Parameter와 차이

구분ParameterMetric
의미넣은 설정나온 결과
타입문자열숫자
여러 번 기록안 됨됨 (step별 이력)
검색=, !=, LIKE>, < 같은 크기 비교도
mlflow.search_runs(filter_string="metrics.mae < 2.0", order_by=["metrics.mae ASC"])
